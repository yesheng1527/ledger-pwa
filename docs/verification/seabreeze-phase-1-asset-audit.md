## 5. 安全与来源检查

`src/assets/assets.test.tsx` 当前对 20 个生产 SVG 执行真实源文件扫描，并要求：

- 恰好一个可用 `viewBox`；
- 无 `<script>`、`<foreignObject>`、`<text>` 或 `<image>`；
- 无 `on*` 事件属性；
- 无 `javascript:`、`vbscript:`；
- 无远程或 data CSS URL；
- 无编码标记字符、嵌入位图或远程 URL；
- 无 emoji 呈现字符；
- 使用一致的圆角描边。

2026-07-26 加强后的结果：1 个测试文件、18 项测试全部通过。现有资产没有需要先行修复的安全违规。

所有现有向量均为项目内独立重绘，来源记录在 `src/assets/ATTRIBUTION.md`。新资产继续采用相同归属说明，不引入远程依赖。
